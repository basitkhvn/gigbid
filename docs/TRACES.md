# Trace exhibits

Generated by `python scripts/make_traces.py` (open profile, synthetic jobs). Each is a PII-masked JSONL of spans (node, tool, LLM calls with tokens/USD/latency) plus a summary. The same data is browsable in the UI at `/runs/<id>` ("Agent run viewer" -> trace) and via `GET /runs/{id}/trace`. These are files in this repo rather than public hosted traces (no LangSmith/Langfuse account was configured).

| Exhibit | File | What to look at |
|---|---|---|
| Skipped scam | [scam_skipped](traces/scam_skipped.jsonl) | Risk Assessor flags; `decide` -> skip; no pricing/writer/tool-write spans |
| Approved proposal | [approved_proposal](traces/approved_proposal.jsonl) | parallel analyst/risk/fit, writer, verifier (claims removed), critic, compliance, `executor` after approval |
| Critic loop | [critic_loop](traces/critic_loop.jsonl) | writer -> verifier -> critic(not ok) -> writer again (max 2) |
| Crash and resume | [crash_and_resume](traces/crash_and_resume.jsonl) | graph torn down while awaiting approval; new process resumes from the checkpoint; submitted once |
